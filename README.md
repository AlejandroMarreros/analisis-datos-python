# analisis-datos-python
Prácticas de análisis de datos con Python utilizando NLTK, SciPy, Seaborn, Matplotlib, Pandas y NumPy.
Análisis de Datos con Python
Práctica de análisis de datos utilizando Python y diferentes librerías para procesamiento de texto, análisis estadístico y visualización de datos.

Tecnologías utilizadas
Python

NLTK

NumPy

Pandas

SciPy

Seaborn

Matplotlib

Ejercicios realizados
Ejercicio 1 - NLTK
Procesamiento de reseñas utilizando:

Tokenización de texto.

Eliminación de palabras vacías (stopwords).

Conteo de palabras clave.

Análisis de sentimiento mediante VADER.

Ejercicio 2 - SciPy
Análisis estadístico de rentabilidad utilizando:

Prueba t de Student.

Comparación de rentabilidad entre productos.

Análisis del p-value.

Optimización de producción.

Ejercicio 3 - Seaborn
Visualización de distribuciones mediante:

Histogramas.

Estimación de densidad KDE.

Comparación de distribuciones entre grupos.

Ejercicio 4 - Matplotlib
Visualización estadística mediante:

Histogramas.

Subplots.

Cálculo de media y mediana.

Líneas verticales para identificar los valores estadísticos.

Objetivo
Fortalecer mis conocimientos en Python, análisis de datos, estadística y visualización mediante ejercicios prácticos utilizando diferentes librerías.
